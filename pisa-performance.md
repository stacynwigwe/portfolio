# PISA Global Performance Explorer  
*Interactive Dashboard built in Looker Studio*

## Overview  
This project examines student achievement across **Math, Reading, and Science** using OECD’s PISA dataset.  
The dashboard visualizes country performance, gender differences, and long-term trends across global education systems.

The goal is to create a **clean, recruiter-ready visualization** that evaluates educational outcomes using interactive analytics.

---

## Objectives  
- Analyze global student performance across core subjects  
- Compare **gender performance (Boy/Girl/Total)**  
- Track **trends over time** across countries  
- Visualize **subject-level differences**  
- Provide insights into achievement gaps and stability  

---

## Dataset  
Source: *OECD PISA – Public Dataset*  
Fields include:  
- **Country**  
- **Year**  
- **Group** (Boy, Girl, Total)  
- **Subject** (Math, Reading, Science)  
- **Score**

## Key Insights  

- Math shows the largest performance spread between the highest and lowest scoring nations.  
- Science remains the most stable subject across years.  
- Reading shows strong gender effects, with girls outperforming boys in many countries.  
- The dashboard provides a clear, interactive way to examine global educational patterns.
